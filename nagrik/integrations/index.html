Connect with ChatGPT
Add Nagrik from ChatGPT’s Plugins area in six steps.
  1. 1

    Open chatgpt.com in a web browser.

  2. 2

    Open Security / Login in settings and enable Developer Mode.

  3. 3

    Go to Plugins.

  4. 4

    Click + and enter Nagrik as the name.

  5. 5

    Enter https://nagrik.in.net/mcp as the server URL.

  6. 6

    Set authentication to No auth, then select Connect.

OpenAI’s plugin guidance
Connect another assistant
These steps work for Claude, Grok, or any tool that supports remote Streamable HTTP MCP servers.
  1. 1

    Open your assistant’s MCP, Connectors, or Tools settings.

  2. 2

    Add a remote or Streamable HTTP server and name it Nagrik.

  3. 3

    Paste https://nagrik.in.net/mcp as the server URL and leave authentication unset.

  4. 4

    Connect, then ask a direct civic question about a locality or project.
